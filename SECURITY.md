# Security

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue or pull request for a security problem.

Include what you found, how to reproduce it, and the impact you expect. We'll acknowledge your report within three working days and keep you updated until it's resolved. We're glad to credit you in the release notes once a fix ships, unless you'd rather stay anonymous.

## Scope

- The packages in this repository: `@actuate/sdk`, `@actuate/runtime`, `@actuate/cli`, `@actuate/providers` and `create-actuate`.
- The hosted platform at `actuate.run`, `run.actuate.run` and `api.actuate.run`. Please test only against your own account and actuators, and don't degrade the service for others (no load testing or denial of service).

## Supported versions

Fixes go into the latest published version of each package.
