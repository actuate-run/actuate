# @actuate/cli

The `actuate` command: init, dev (local workerd), check (replay-safety linter), deploy, run, logs, providers.

```bash
npx actuate dev       # run locally on workerd
npx actuate check     # lint for side effects outside ctx.step.do
npx actuate deploy    # deploy to actuate.run
```
